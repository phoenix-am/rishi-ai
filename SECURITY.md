# Security Policy

## Supported Versions

Only the current master/main branch receives security updates.

## Reporting a Vulnerability

We take the security of Rishi AI seriously. If you discover a security vulnerability, please report it immediately:

- **Do not** open a public GitHub issue.
- Please email reports directly to: `security@rishi.ai` (or the founder's designated security contact).

Please include the following details in your report:

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue (including proof-of-concept scripts or configuration details if available).
- Any recommended mitigations.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to resolve the issue as quickly as possible.
